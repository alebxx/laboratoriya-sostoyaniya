# Лаборатория состояния

Исследовательский проект: сайт, на котором человек ведёт дневник субъективного стресса, записывает пульс и давление, проходит короткий тест на внимание (PVT-B) и сам проверяет гипотезы о связях между этими показателями.

**Это не медицинский инструмент.** Сайт не ставит диагнозов, не определяет «уровень стресса» и не сравнивает показатели с нормами.

**Приватность.** У сайта нет сервера, регистрации и аналитики. Все данные хранятся только в браузере пользователя. Их можно выгрузить (CSV, JSON), загрузить обратно и полностью удалить.

## Как запустить на своём компьютере

Нужен Node.js версии 20 или новее. На этом компьютере он лежит в папке `~/.local/node`. Чтобы терминал его нашёл, в каждом новом окне терминала сначала выполните:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
```

Затем в папке проекта:

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который появится в терминале (обычно http://localhost:5173).

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | Запускает автоматические тесты (расчёты, экспорт, импорт) |
| `npm run build` | Собирает готовый сайт в папку `dist/` |
| `npm run preview` | Показывает собранный сайт локально |

## Структура папок

```
index.html            — каркас страницы: шапка, меню, место для содержимого
src/
  main.js             — запуск сайта
  router.js           — какая страница показывается по какому адресу
  config.js           — ВСЕ настраиваемые числа (длительность теста, пороги, сроки)
  db/                 — хранение данных в браузере
    db.js             — структура базы и миграции
    repo.js           — простые функции «сохранить / прочитать / удалить»
    exportImport.js   — выгрузка и загрузка данных
  logic/              — расчёты без интерфейса (их проверяют тесты)
  data/               — тексты (в том числе заглушки для текстов из источников)
  pages/              — страницы сайта, по файлу на страницу
  ui/                 — общие элементы: меню, тема, помощники
  styles/             — оформление (theme.css — цвета светлой и тёмной темы)
public/               — файлы, которые копируются как есть (иконка, офлайн-режим)
tests/                — автоматические тесты
docs/
  methodology.md      — методические решения и источники
  todo-content.md     — какие тексты нужно вставить из источников
```

## Где что менять

| Хочу изменить… | Файл |
|---|---|
| Длительность теста, пороги, число тренировочных сеансов, границу суток | `src/config.js` |
| Общие тексты (предупреждения на главной и при первом входе) | `src/data/texts.js` |
| Поля дневника: шкалы, варианты настроения, список причин | `src/logic/diary.js` |
| Текст мягкой заботы | `src/data/messages.js` |
| Параметры теста внимания (длительность, интервалы, пороги, число тренировочных сеансов) | `src/config.js` → `PVT` |
| Инструкция к тесту и текст самопроверки | `src/data/pvtTexts.js` |
| Как идёт тест (тайминг, фальстарты, прерывание) | `src/logic/pvtRunner.js` |
| Какие сеансы входят в анализ | `src/logic/sessionFilter.js` |
| Когда показывать мягкую заботу (порог стресса, число дней) | `src/config.js` → `CARE` |
| Тексты из научных источников (вопросы, советы) | файлы в `src/data/`, список — в `docs/todo-content.md` |
| Цвета | `src/styles/theme.css` |
| Пункты меню | `index.html` (меню) и `src/router.js` (адреса страниц) |

## Как опубликовать на GitHub Pages

Подробная инструкция будет добавлена на этапе 10. Кратко: `npm run build` создаёт папку `dist/` со статическими файлами, и её содержимое выкладывается на GitHub Pages. Все пути в сборке относительные, поэтому сайт работает в любой папке.
