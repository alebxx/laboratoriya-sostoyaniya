# Заглушки: что нужно заполнить текстами из источников

Тексты, для которых нужен научный источник, разработчик не придумывает. В коде такие места помечены `TODO: вставить из источника [...]` или `TODO: сверить с источником [...]`. Список пополняется на каждом этапе.

Найти все пометки в коде можно поиском по слову `TODO` в папке `src/`.

## Уже в коде

| Где | Что | Источник |
|---|---|---|
| `src/config.js` → `PVT.isiMinMs`, `PVT.isiMaxMs` | Сверить интервалы между сигналами (сейчас 1–4 с) | Basner, Mollicone, Dinges (2011) |
| `src/config.js` → `PVT.lapseMs` | Сверить порог пропуска (сейчас 355 мс) | Basner, Mollicone, Dinges (2011) |
