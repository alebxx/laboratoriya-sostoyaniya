# Заглушки: что нужно заполнить текстами из источников

Тексты, для которых нужен научный источник, разработчик не придумывает. В коде такие места помечены `TODO: вставить из источника [...]` или `TODO: сверить с источником [...]`. Список пополняется на каждом этапе.

Найти все пометки в коде можно поиском по слову `TODO` в папке `src/`.

## Уже в коде

| Где | Что | Источник |
|---|---|---|
| `src/config.js` → `PVT.isiMinMs`, `PVT.isiMaxMs` | Сверить интервалы между сигналами (сейчас 1–4 с) | Basner, Mollicone, Dinges (2011) |
| `src/config.js` → `PVT.lapseMs` | Сверить порог пропуска (сейчас 355 мс) | Basner, Mollicone, Dinges (2011) |
| `src/config.js` → `PVT.responseTimeoutMs` | Сверить, через сколько секунд без ответа засчитывать пропуск (сейчас 30 с) | Basner, Mollicone, Dinges (2011) |
| `docs/methodology.md` → 7.2, 7.3 | Сверить порог фальстарта (100 мс) и какие показатели PVT-B названы наиболее чувствительными (1/RT, пропуски) | Basner et al. (2011) |
| `src/data/pvtTexts.js` → `SELFCHECK_TYPICAL` | Сверить «типичная медиана у бодрого человека около 200–300 мс» | Basner et al. (2011); Lim, Dinges (2010) |
| `src/data/messages.js` → `CARE_MESSAGE` | Заголовок и текст мягкой заботы (к кому обратиться; телефон доверия — только из официального источника) | Рекомендации школьной психологической службы / текст автора, согласованный с психологом |
