# Заглушки: что нужно заполнить текстами из источников

Тексты, для которых нужен научный источник, разработчик не придумывает. В коде такие места помечены `TODO: вставить из источника [...]` или `TODO: сверить с источником [...]`. Пока заглушка не заполнена, на её месте на сайте виден текст «TODO…» — это сделано специально, чтобы ни одна не потерялась.

Найти все пометки в коде можно поиском по слову `TODO` в папке `src/`.

## Решения, которые стоит согласовать с руководителем

Это не тексты из источников, а проектные решения разработчика. Все они описаны в `docs/methodology.md`:

- что убирается из выгрузки для исследователя, а что остаётся (раздел 13);
- граница суток 4:00, порог «данных мало» 7 точек, 3 тренировочных сеанса, медиана как статистика сравнения (разделы 3, 8, 7.7, 9.4);
- две оси на одном графике при сравнении показателей (раздел 8).
